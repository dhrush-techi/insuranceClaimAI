//idea
Now we add several novel layers, both algorithmic and UX:

1) Multi-Agent, Multi-Phase Pipeline (Analyzer / Investigator / Reasoning Engine / Advocate)

Instead of one opaque LLM call, we explicitly implement:

Analyzer agent
Extracts:

denial_reason_raw (verbatim quote),

denial_category (Medical Necessity / Prior Auth / Coding Error / Administrative),

insurer_name,

denial_code (CARC if visible).

Investigator agent
Searches only the patient’s medical docs for:

Evidence snippets, each with:

Date, section (e.g., “OPD note, 2025-01-10”),

Span indices in text (for highlighting),

Type of evidence (failed therapy, severity, risk, coding proof).

Reasoning Engine

Combines Analyzer + Investigator results.

Computes confidence score (0–100).

Classifies each case into:

AUTO_DRAFT (high confidence),

NEEDS_REVIEW (medium),

INCOMPLETE_EVIDENCE (low / missing docs).

Advocate agent

Selects a template based on denial category.

Generates:

Full Appeal Letter,

Supporting Evidence Report (a structured justification list).

Novelty: Explicit pipeline with intermediate JSON artifacts + confidence-based routing is more transparent and patentable than a monolithic black box.

2) Per-User “Appeal Case Graph”

Instead of flat history, we treat each denial as a case node in a per-user graph:

Nodes:

DenialCase (denial letter + metadata),

EvidenceItem (snippet, date, source),

AppealDraft (with versioning),

Feedback (user labeling, outcome).

Edges describe:

DENIED_FOR, SUPPORTED_BY, APPEALED_AS, EVALUATED_WITH_FEEDBACK.

We don’t need a complex graph DB to implement the idea, but the concept is graph-structured. This is strong in papers/patents because you model the lifecycle of appeals, not just one upload.

3) Evidence Traceability & Highlighting

Each evidence snippet stores:

source_doc_id

start_char, end_char in the original raw text

evidence_type (symptom severity, prior treatment failure, risk of non-treatment, etc.)

Frontend lets users:

Hover or click an evidence chip → see exact quote + location (“Page 3, Clinical Note dated 2025-01-10”).

See “Why this evidence?” explanation from the Reasoning Engine.

Novelty: Traceable AI: every chatbot answer and every appeal sentence can point back to specific evidence spans, improving auditability and trust.

4) Active Learning from User Feedback

We add a feedback loop:

User can:

👍/👎 Appeal Letter,

👍/👎 individual Evidence Items,

Mark evidence as “Missing” or “Wrong”.

Backend writes to a feedback table:

user_id, case_id, evidence_id, label, comment.

Next runs:

Adjust weights when scoring evidence (e.g., down-weight types that are often rejected by users).

(Future extension) Train new scoring model / re-rank LLM suggestions.

Novelty: System continuously adapts to how real users and doctors judge evidence quality and letter usefulness.

5) Policy & Fairness Guardrails

We inject a Policy & Fairness Check step:

Ensures:

Tone is professional, non-aggressive.

Mentions relevant regulatory items (e.g., “medical necessity” definitions) but does not promise legal outcomes.

Avoids discriminatory language / disallowed suggestions.

If guardrail step flags issues, marks case as NEEDS_REVIEW instead of auto-sending.

Novelty: Regulatory-aware appeal drafting with explicit filtering and gating improves safety and compliance.

6) Multi-Scenario “What-If” Simulation

New feature: Simulate how adding certain evidence might change the outcome:

User can select hypothetical new documents:

e.g., “Add MRI report from 2025-02-11 with X findings”.

Backend recomputes confidence and high-level reasoning without fully generating a new letter.

Useful for:

Telling user: “If you get a letter from Dr. X documenting prior failed therapies, confidence jumps from 62% → 88%.”

Novelty: Decision support for what documentation to obtain next, not just post-hoc explanation.

@app.post("/api/upload", response_model=UploadResponse)
async def upload_case(
  user_id: str = Form(...),
  denial_letter: Optional[UploadFile] = File(None),
  medical_record: Optional[UploadFile] = File(None),
):
  if not denial_letter and not medical_record:
    raise HTTPException(status_code=400, detail="At least one file is required.")

  case_id = f"case_{datetime.utcnow().strftime('%Y%m%d%H%M%S%f')}"

  denial_path: Optional[Path] = None
  medical_path: Optional[Path] = None

  if denial_letter:
    fn = _safe_filename("denial", denial_letter.filename or "denial")
    denial_path = UPLOAD_DIR / fn
    with open(denial_path, "wb") as f:
      f.write(await denial_letter.read())

  if medical_record:
    fn = _safe_filename("medical", medical_record.filename or "medical")
    medical_path = UPLOAD_DIR / fn
    with open(medical_path, "wb") as f:
      f.write(await medical_record.read())

  # Phase 1: OCR + normalization
  denial_text = ""
  medical_text = ""
  if denial_path:
    denial_text = normalize_text(extract_text_from_file(denial_path))
  if medical_path:
    medical_text = normalize_text(extract_text_from_file(medical_path))

  # Phase 2: Analyzer
  if not denial_text:
    denial_category = "Administrative"
    denial_reason_raw = "Denial letter could not be parsed."
    insurer_name = None
    denial_code = None
  else:
    analysis = analyze_denial_text(denial_text)
    denial_category = analysis.denial_category
    denial_reason_raw = analysis.denial_reason_raw
    insurer_name = analysis.insurer_name
    denial_code = analysis.denial_code

  # Phase 3: Investigator
  evidence = extract_evidence(medical_text, denial_category, denial_reason_raw)

  # Phase 4: Reasoning
  reasoning = reason_about_case(denial_category, denial_reason_raw, evidence.evidence_snippets)

  # Phase 5: Advocate (auto-draft if confident)
  letter_text = None
  if reasoning.auto_draft:
    letter = generate_letter(
      template_id=_default_template_id(denial_category),
      denial_category=denial_category,
      denial_reason=denial_reason_raw,
      insurer_name=insurer_name,
      evidence_snippets=evidence.evidence_snippets,
      reasoning_summary=reasoning.reasoning_summary,
    )
    letter_text = letter.letter_text

  record = CaseRecord(
    id=case_id,
    user_id=user_id,
    created_at=datetime.utcnow().isoformat() + "Z",
    denial_filename=denial_letter.filename if denial_letter else None,
    medical_filename=medical_record.filename if medical_record else None,
    denial_category=denial_category,
    insurer_name=insurer_name,
    confidence_score=reasoning.confidence_score,
    status="processed",
    denial_reason_raw=denial_reason_raw,
    reasoning_summary=reasoning.reasoning_summary,
    evidence_summary=evidence.summary,
    letter_text=letter_text,
    denial_text=denial_text,
    medical_text=medical_text,
  )
  save_case(record)

  return UploadResponse(
    id=record.id,
    user_id=record.user_id,
    created_at=record.created_at,
    denial_filename=record.denial_filename,
    medical_filename=record.medical_filename,
    denial_category=record.denial_category,
    insurer_name=record.insurer_name,
    confidence_score=record.confidence_score,
    status=record.status,
  )

  if "authorization" in c:
    return "prior_auth"
  if "coding" in c:
    return "coding_error"
  return "administrative"

def chat(req: ChatRequest):
    append_chat(req.user_id, "user", req.message)

    cases = list_cases_for_user(req.user_id)
    latest_case = cases[0] if cases else None

    if not latest_case:
        answer = (
            "You haven't uploaded any denial letters or medical records yet.\n"
            "Please upload them so I can answer accurately."
        )
    else:
        q = req.message.lower()
        denial_text = (latest_case.denial_text or "").lower()
        medical_text = (latest_case.medical_text or "").lower()

        # ---------- WHY DENIED ----------
        if "why" in q and "denied" in q:
            answer = (
                f"Your claim was denied by the insurer due to the following reason:\n\n"
                f"📝 **Denial Category:** {latest_case.denial_category}\n"
                f"🏥 **Insurance Company:** {latest_case.insurer_name or 'Not specified'}\n\n"
                f"📄 **Exact reason from denial letter:**\n"
                f"\"{latest_case.denial_reason_raw}\""
            )

        # ---------- MEDICAL EVIDENCE ----------
        elif "evidence" in q or "medical" in q:
            if not latest_case.evidence_summary:
                answer = (
                    "I could not find clear medical evidence in the uploaded records "
                    "that directly supports this appeal."
                )
            else:
                answer = (
                    "I found the following medical evidence in your records that supports your case:\n\n"
                    f"{latest_case.evidence_summary}\n\n"
                    "This evidence is relevant to challenging the insurer's denial."
                )

        # ---------- SUCCESS CHANCE ----------
        elif "chance" in q or "success" in q or "appeal" in q:
            score = latest_case.confidence_score or 0
            verdict = (
                "strong chance of approval"
                if score >= 80
                else "moderate chance of approval"
                if score >= 60
                else "low chance of approval"
            )

            answer = (
                f"Based on your documents, the appeal has a **{verdict}**.\n\n"
                f"📊 **Confidence Score:** {score:.0f}%\n\n"
                f"📘 **Reasoning:**\n{latest_case.reasoning_summary}"
            )

        # ---------- CODING ----------
        elif "code" in q or "cpt" in q or "icd" in q:
            matches = [
                line for line in (latest_case.denial_text or "").splitlines()
                if any(k in line.lower() for k in ["cpt", "icd", "code"])
            ]

            answer = (
                "These sections from the denial letter mention billing or coding:\n\n"
                + ("\n".join(matches[:6]) if matches else "No explicit CPT/ICD codes were mentioned.")
            )

        # ---------- FALLBACK ----------
        else:
            answer = (
                "I can answer questions like:\n\n"
                "• Why was my claim denied?\n"
                "• What medical evidence supports me?\n"
                "• Will my appeal succeed?\n"
                "• Is this a coding or authorization issue?\n\n"
                "Ask one of the above for accurate answers."
            )

    msg = append_chat(req.user_id, "bot", answer)
    return ChatMessage(**msg)

@app.post("/api/generate-letter")
def generate_letter_endpoint(req: GenerateLetterRequest):
  # Verify case belongs to user
  cases = list_cases_for_user(req.user_id)
  case = next((c for c in cases if c.id == req.case_id), None)
  if not case:
    raise HTTPException(status_code=404, detail="Case not found")

  t_id = req.template_id
  letter = generate_letter(
    template_id=t_id,
    denial_category=case.denial_category or "",
    denial_reason=case.denial_reason_raw or "",
    insurer_name=case.insurer_name,
    evidence_snippets=case.evidence_summary or "",
    reasoning_summary=case.reasoning_summary or "",
  )

  content = letter.letter_text

  fmt = req.format.lower()
  if fmt == "txt":
    return StreamingResponse(
      io.BytesIO(content.encode("utf-8")),
      media_type="text/plain",
      headers={"Content-Disposition": "attachment; filename=appeal.txt"},
    )
  if fmt == "docx":
    buffer = io.BytesIO()
    doc = Document()
    for line in content.splitlines():
      doc.add_paragraph(line)
    doc.save(buffer)
    buffer.seek(0)
    return StreamingResponse(
      buffer,
      media_type="application/vnd.openxmlformats-officedocument.wordprocessingml.document",
      headers={"Content-Disposition": "attachment; filename=appeal.docx"},
    )
  if fmt == "pdf":
    buffer = io.BytesIO()
    p = canvas.Canvas(buffer)
    text_obj = p.beginText(50, 800)
    for line in content.splitlines():
      text_obj.textLine(line)
    p.drawText(text_obj)
    p.showPage()
    p.save()
    buffer.seek(0)
    return StreamingResponse(
      buffer,
      media_type="application/pdf",
      headers={"Content-Disposition": "attachment; filename=appeal.pdf"},
    )

  raise HTTPException(status_code=400, detail="Unsupported format")

import uuid
from typing import List, Dict

def extract_evidence(medical_text: str, reason_id: str) -> List[Dict]:
    """
    Extract evidence snippets aligned with denial reason.
    """

    evidence = []

    for line in medical_text.splitlines():
        l = line.lower()

        if "failed" in l or "ineffective" in l:
            evidence.append({
                "evidence_id": str(uuid.uuid4()),
                "reason_id": reason_id,
                "type": "FAILED_THERAPY",
                "text": line.strip()
            })

        elif "severe" in l or "pain" in l:
            evidence.append({
                "evidence_id": str(uuid.uuid4()),
                "reason_id": reason_id,
                "type": "SEVERITY",
                "text": line.strip()
            })

        elif "risk" in l or "worsen" in l:
            evidence.append({
                "evidence_id": str(uuid.uuid4()),
                "reason_id": reason_id,
                "type": "RISK",
                "text": line.strip()
            })

    return evidence

# Simple in-memory + JSON fallback (dev mode only)
_CASES: Dict[str, CaseRecord] = {}
_USER_CASE_IDS: Dict[str, List[str]] = {}

def save_case(case: CaseRecord) -> None:
  _CASES[case.id] = case
  _USER_CASE_IDS.setdefault(case.user_id, []).insert(0, case.id)
  path = CASE_DIR / f"{case.id}.json"
  import json
  with open(path, "w", encoding="utf-8") as f:
    json.dump(asdict(case), f, ensure_ascii=False, indent=2)

def list_cases_for_user(user_id: str) -> List[CaseRecord]:
  ids = _USER_CASE_IDS.get(user_id, [])
  return [c for case_id in ids if (c := _CASES.get(case_id))]

def load_all_cases_from_disk() -> None:
  import json
  from uuid import uuid4
  for path in CASE_DIR.glob("*.json"):
    with open(path, "r", encoding="utf-8") as f:
      data = json.load(f)
    case = CaseRecord(**data)
    _CASES[case.id] = case
    _USER_CASE_IDS.setdefault(case.user_id, []).append(case.id)

from __future__ import annotations
from dataclasses import dataclass
from typing import Optional, Dict

@dataclass
class DenialAnalysis:
  denial_reason_raw: str
  denial_category: str
  insurer_name: Optional[str]
  denial_code: Optional[str]

CATEGORIES = {
  "medical necessity": "Medical Necessity",
  "not medically necessary": "Medical Necessity",
  "prior authorization": "Prior Authorization",
  "pre authorization": "Prior Authorization",
  "coding": "Coding Error",
  "icd": "Coding Error",
  "cpt": "Coding Error",
  "administrative": "Administrative",
  "late filing": "Administrative",
  "timely filing": "Administrative",
}

def analyze_denial_text(text: str) -> DenialAnalysis:
  lower = text.lower()
  category = "Administrative"
  for key, value in CATEGORIES.items():
    if key in lower:
      category = value
      break

  insurer_name = _extract_insurer_name(text)
  denial_reason_raw = _extract_reason_snippet(text)
  denial_code = _extract_code(text)

  return DenialAnalysis(
    denial_reason_raw=denial_reason_raw,
    denial_category=category,
    insurer_name=insurer_name,
    denial_code=denial_code,
  )

def _extract_insurer_name(text: str) -> Optional[str]:
  for line in text.splitlines()[:15]:
    if "insurance" in line.lower() or "insurer" in line.lower() or "health" in line.lower():
      return line.strip()
  return None

def _extract_reason_snippet(text: str) -> str:
  for line in text.splitlines():
    lower = line.lower()
    if "denied" in lower or "denial" in lower or "not covered" in lower:
      return line.strip()
  return text[:400]

def _extract_code(text: str) -> Optional[str]:
  import re
  m = re.search(r"\b(CO|PR|OA)-?\d{1,3}\b", text)
  if m:
    return m.group(0)
  return None

def to_json(da: DenialAnalysis) -> Dict:
  return {
    "denial_reason_raw": da.denial_reason_raw,
    "denial_category": da.denial_category,
    "insurer_name": da.insurer_name,
    "denial_code": da.denial_code,
  }

@dataclass
class EvidenceBundle:
  evidence_snippets: str
  summary: str

def extract_evidence(medical_text: str, denial_category: str, denial_reason: str) -> EvidenceBundle:
  """
  Very simplified: In production, use RAG + LLM to pull relevant sections.
  Here we just heuristically search for key phrases.
  """
  lines = [l.strip() for l in medical_text.splitlines() if l.strip()]
  key_phrases = []

  lower_category = denial_category.lower()
  if "medical necessity" in lower_category:
    key_phrases = ["severe", "failed", "trial", "risk", "complication", "prior treatment", "conservative"]
  elif "coding" in lower_category:
    key_phrases = ["cpt", "icd", "procedure", "code", "billed"]
  elif "authorization" in lower_category:
    key_phrases = ["authorization", "pre-auth", "approval", "reference number"]
  else:
    key_phrases = ["claim", "policy", "coverage"]

  snippets = [line for line in lines if any(k in line.lower() for k in key_phrases)]
  selected = "\n".join(snippets[:40])

  summary = (
    f"Evidence extracted for category '{denial_category}'. "

from __future__ import annotations
from pathlib import Path
from typing import Tuple

import pdfplumber
from PIL import Image
import pytesseract

def extract_text_from_file(path: Path) -> str:
  suffix = path.suffix.lower()
  if suffix in [".pdf"]:
    return _extract_text_from_pdf(path)
  if suffix in [".png", ".jpg", ".jpeg", ".bmp", ".tiff"]:
    return _extract_text_from_image(path)
  # Fallback for doc/docx etc – in production use python-docx or external service
  try:
    with open(path, "r", encoding="utf-8", errors="ignore") as f:
      return f.read()
  except Exception:
    return ""

def _extract_text_from_pdf(path: Path) -> str:
  text_chunks = []
  with pdfplumber.open(path) as pdf:
    for page in pdf.pages:
      text_chunks.append(page.extract_text() or "")
  return "\n".join(text_chunks)

def _extract_text_from_image(path: Path) -> str:
  img = Image.open(path)
  return pytesseract.image_to_string(img)

def normalize_text(raw: str) -> str:
  """Basic normalization: strip weird chars, unify whitespace, etc."""
  import re
  text = raw.replace("\r", "\n")
  text = re.sub(r"[^\S\n]+", " ", text)
  text = re.sub(r"\n{3,}", "\n\n", text)
  text = text.strip()
  return text

from __future__ import annotations
from dataclasses import dataclass
from typing import Dict

@dataclass
class ReasoningResult:
  confidence_score: float
  auto_draft: bool
  reasoning_summary: str

def reason_about_case(denial_category: str, denial_reason: str, evidence_snippets: str) -> ReasoningResult:
  """
  Simple heuristic – in production, this can be an LLM-based legal reasoner.
  """
  coverage = len(evidence_snippets.splitlines())
  # Fake "confidence" based on presence of evidence and severity words
  score = min(95.0, 40.0 + coverage * 2.0)
  if "failed" in evidence_snippets.lower() or "severe" in evidence_snippets.lower():
    score += 10

  score = max(0.0, min(100.0, score))
  auto_draft = score >= 60.0

  summary = (
    f"Denial category '{denial_category}'. Evidence lines: {coverage}. "
    f"Computed confidence score {score:.0f}%. "
    f"{'Proceed with auto-draft.' if auto_draft else 'Recommend manual review.'}"
  )

  return ReasoningResult(confidence_score=score, auto_draft=auto_draft, reasoning_summary=summary)

def to_json(rr: ReasoningResult) -> Dict:
  return {
    "confidence_score": rr.confidence_score,
    "auto_draft": rr.auto_draft,
    "reasoning_summary": rr.reasoning_summary,
  }
